# short_phronesis_measure_processing
This project contains code to ingest Short Phronesis Measure Qualtrics survey output files into Julia, compute relevant statistics, and display the results in a meaninful way. McLoughlin's Short Phronesis Measure is documented here: https://www.jubileecentre.ac.uk/project/phronesis-developing-and-validating-a-short-measure-of-practical-wisdom/
